# Generated figures

These figures are generated by `python3 scripts/plot_benchpress_style.py` from
the pinned score matrix and experiment JSON/CSV artifacts.

The plotted primary matrix is 59 models × 165 evaluations with 1,967 reported
cells (20.2054% density) and 7,768 rank-1 imputations. Matched-fold rank-1 error
is 3.005264 MAE and 1.603026 MedAE; the median fold MedAE is 1.609435. Strict
random-cell validation is 2.834996/1.526795, while leave-one-suite-block-out is
5.612789/3.525174 at rank 1 and is best at rank 5
(4.952972/3.055638). These protocols must not be read as interchangeable.

- `matrix_observation_pattern`: published versus missing cells, matching the
  compact BenchPress score-coverage view.
- `matrix_completed_rank1`: published normalized scores beside the selected
  bias-ALS rank-1 point estimates. Translucent cells are imputed.
- `benchpress_style_validation_rank1`: bias-ALS rank sweep, out-of-fold parity,
  suite errors, and the absolute-error distribution.
- `soft_impute_rank_sweep`: the exact raw/logit iterative truncated-SVD method
  used for BenchPress's rank-discovery figure, with both MedAPE and MedAE views.
- `probe_selection_rank1`: BenchPress-style random/greedy scorecard
  reconstruction, strict held-out-model validation, and literal row-average
  prediction. The exact selected probe lists are in
  `experiments/probe_selection_results_rank1.json` and span multiple suites.
- `probe_informativeness_rank1`: one-probe candidate ranking with suite and
  observed-model coverage.

For the probe figure, all-known five/ten-probe MedAE is
1.481124/1.196456, hidden-only is 1.612112/1.539134, and held-out-model
hidden-cell MedAE is 1.951271/1.879857. Literal-average MAE is
3.203489/2.908513 all-known and 1.684778/1.231976 held out.

PNG files are convenient for review; PDFs are the vector publication assets.

Regenerate the probe figures with `python3 scripts/plot_probe_selection.py`
after running `python3 experiments/run_probe_selection.py`.
