# Generated figures

These figures are generated by `python3 scripts/plot_benchpress_style.py` from
the pinned score matrix and experiment JSON/CSV artifacts.

- `matrix_observation_pattern`: published versus missing cells, matching the
  compact BenchPress score-coverage view.
- `matrix_completed_rank1`: published normalized scores beside the selected
  bias-ALS rank-1 point estimates. Translucent cells are imputed.
- `benchpress_style_validation_rank1`: bias-ALS rank sweep, out-of-fold parity,
  suite errors, and the absolute-error distribution.
- `soft_impute_rank_sweep`: the exact raw/logit iterative truncated-SVD method
  used for BenchPress's rank-discovery figure, with both MedAPE and MedAE views.

PNG files are convenient for review; PDFs are the vector publication assets.
